# Interface

Mode: Operate. Familiar Streamlit controls, two parallel team columns and a single prediction action. No decorative graphics. Warm off-white page (#faf8f4), dark green-black text (#252d2a), muted brick action (#ad472e). Native Streamlit font, spacing and focus behavior. Main tabs: draft, model quality, project information.

Every input has a visible label. Duplicate heroes disable prediction. Loading and API errors are explicit. Editing inputs invalidates displayed results. Historical-data context stays visible near the title. At small widths rely on Streamlit column stacking and inspect the actual app.

Minute-five extension inherits these colors and native controls. Its first tab contains two team columns, searchable five-hero multiselects and seven explicitly labeled totals per team. Empty statistics use blank number inputs, prediction stays disabled until complete. One button loads an actual training example. Model comparison and provenance are collapsible below the form. Historical dates differ per mode and must remain explicit.
